# 贪吃蛇 SnakeBite · 玩法说明

一款带强化系统的贪吃蛇。开局先选一项强化，之后每吃 5 个食物再选一次，越吃越快、越吃越花。

## 一、操作

| 场景 | 操作 |
|---|---|
| 键盘 | 方向键或 `W` `A` `S` `D` 转向 |
| 键盘 | `R` 重开一局，`Esc` 返回主页 |
| 触屏 | 右下角方向键（仅触屏设备显示，按下立即转向） |
| 触屏 | 在棋盘上滑动转向，可连续滑动不必抬手 |
| 强化界面 | 点击三张卡中的一张；键盘可用 `Tab` / 方向键切换后回车 |

规则细节：不允许 180° 直接掉头；一帧内多次转向只有最后方向在下一个移动节拍生效。

## 二、基本规则

- 棋盘 **24 × 14** 格（1280×720 下的 40 像素方格）
- 撞墙或撞到自己的身体即结束；撞到身体时尾巴尖那一格会让开，不会误判
- 吃一个食物身体加长一格、分数增加，节奏自动变快（每吃一个约快 2.5%）
- 结束面板显示本局分数、吃到的食物数、历史最佳，可直接再来一局
- 最佳分保存在 `user://snake_best.cfg`，重开游戏不丢

## 三、计分

单个食物得分 = **10 + 双倍分层数 × 10 + 疾行层数 × 5**

| 情况 | 单个食物 |
|---|---|
| 无强化 | 10 |
| 双倍分 ×1 | 20 |
| 双倍分 ×2 + 疾行 ×1 | 35 |
| 双倍分 ×3 + 疾行 ×3 | 55 |

界面左上角实时显示「分数 · 已吃个数 · 最佳」。

## 四、强化一览

| 强化 | 上限 | 效果 | 取舍 |
|---|---|---|---|
| 护盾 | 3 层 | 抵挡一次致命撞击；抵消后停顿 0.8 秒供你转向，蛇头显示蓝色描边 | 纯收益，撞两次才用完两层 |
| 穿墙 | 1 层 | 撞墙时从对面穿出，不再被墙困死 | 只有一层，早拿收益最大 |
| 双倍分 | 3 层 | 每个食物多 10 分 | 分数收益，但蛇变长更快、更难控 |
| 疾行 | 3 层 | 移速提升约 11%/层，每个食物额外 +5 分 | 高风险高回报，叠满后极快 |
| 缓行 | 2 层 | 移速下降约 12%/层 | 用分数换容错，新手向 |
| 分数 +50 | 不限 | 立即加 50 分，不占强化位 | 其余强化满级时的兜底选项 |

机制说明：

- **开局必选一次**，选完才开始移动（避免一上来就撞墙）
- **每吃 5 个食物触发一次**，游戏暂停、弹出三张随机卡
- 已满级的强化不再出现；可用项不足 3 个时用「分数 +50」补齐
- 强化状态常驻显示在左下角，例如 `强化：护盾×2  穿墙  双倍分×1`

## 五、上手建议

1. **新手**：开局选护盾或缓行，先把节奏摸清；第 5 个食物后补穿墙，减少被墙逼死的概率
2. **冲分**：开局双倍分，之后优先疾行叠层；穿墙用来救急
3. 护盾抵消后那 0.8 秒是唯一的救命窗口，立刻往空地方向掉头
4. 蛇越长越贴着边走越危险，中段绕圈留出回旋空间

## 六、开发与验证

```
scenes/game.tscn + scripts/game.gd   玩法与强化逻辑（单文件，约 280 行）
tests/smoke.tscn                     无头自检：开局强化 / 5 个触发 / 穿墙 / 护盾 / 死亡
docs/玩法说明.md                      本文件
```

跑自检（无需图形界面）：

```
godot --headless --path . tests/smoke.tscn --quit-after 200
```

输出 `SMOKE PASS` 即全部通过；失败会逐条打印 `SMOKE FAIL: 原因`。

导出双端见根目录 `README.md` 的「导出」一节。
